📄 Generate AWR Reports
ℹ️ Required Oracle Privileges — no DBA role needed
-- Run on Oracle as SYSDBA: CREATE USER awrportal IDENTIFIED BY "YourPassword123"; GRANT CREATE SESSION TO awrportal; GRANT SELECT_CATALOG_ROLE TO awrportal; -- read-only DBA_HIST_* access, no data access GRANT EXECUTE ON SYS.DBMS_WORKLOAD_REPOSITORY TO awrportal;
SELECT_CATALOG_ROLE grants read-only access to all DBA_* and V$ views needed by AWR report generation. It does NOT grant access to application table data and is NOT the DBA role. Uses oracledb thin mode — no Oracle Client installation required on the portal server.
